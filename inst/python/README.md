# canobspy

Python core of [canObsR](https://github.com/umr-amap/canObsR): Time-SIFT orthomosaics of long series of drone
flights with OpenDroneMap (default) or Agisoft Metashape, and their co-registration with AROSICS.

Normally installed by `canObsR::canobs_setup()` from R. To install it alone:

```
conda env create -f environment.yml
conda activate canobs
pip install --no-deps .
```
